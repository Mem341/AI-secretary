# 🗓 AI-secretary

Особистий Telegram-секретар із відкритим кодом. Пишете йому як людині — текстом, голосом, скріншотом чи
пересланою перепискою — і ШІ-агенти ставлять зустрічі в Google Calendar (з Google Meet або Zoom), показують
розклад, переносять і скасовують, приймають запрошення, читають, пишуть і відповідають на листи Gmail. Про нові
запрошення (з кнопками ✅ Прийняти / ❌ Відхилити) і нові листи бот повідомляє одразу.

Кожен розгортає **власну копію на Vercel** (одна кнопка) — безкоштовно для однієї людини, без серверів.

**Node.js + TypeScript · Vercel Functions · OpenRouter · Zoom (необовʼязково) · без бази даних**

> 🤖 **ШІ-агентам, які розгортають бота:** спершу прочитайте [AGENTS.md](AGENTS.md). Проєкт готовий — нічого не
> переносити й не перепроєктовувати; у користувача питати лише значення змінних середовища.

> 🔒 **Кожна копія служить рівно одній людині** — тій, чий Telegram ID вказано в `OWNER_TELEGRAM_ID`.
> Повідомлення від усіх інших бот мовчки ігнорує: сторонній навіть не дізнається, що бот працює.

## 🚀 Розгортання за 5 хвилин

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2FMem341%2FAI-secretary&env=OWNER_TELEGRAM_ID%2CTELEGRAM_BOT_TOKEN%2COPENROUTER_API_KEY%2CGOOGLE_CLIENT_JSON&envDescription=Your+numeric+Telegram+ID+%28%40userinfobot%29%2C+bot+token+%28%40BotFather%29%2C+OpenRouter+API+key%2C+the+downloaded+JSON+of+a+Google+Desktop+app+OAuth+client&envLink=https%3A%2F%2Fgithub.com%2FMem341%2FAI-secretary%23deploy&project-name=ai-secretary&repository-name=ai-secretary)

1. **Підготуйте чотири речі** (покроково — [docs/what-you-need.md](docs/what-you-need.md)):

   | Змінна | Що це | Де взяти |
   |---|---|---|
   | `TELEGRAM_BOT_TOKEN` | токен вашого бота | [@BotFather](https://t.me/BotFather) → `/newbot` |
   | `OWNER_TELEGRAM_ID` | ваш **числовий** Telegram ID | напишіть [@userinfobot](https://t.me/userinfobot) |
   | `OPENROUTER_API_KEY` | ключ до ШІ | [openrouter.ai/keys](https://openrouter.ai/keys) |
   | `GOOGLE_CLIENT_JSON` | JSON-файл Google-клієнта типу **Desktop app** (доступ до Calendar і Gmail) | Google Cloud Console, 5 хвилин — [інструкція](docs/what-you-need.md#4-google-json-клієнта-desktop-app) |

   Більше нічого не треба — **навіть бази даних**: голосові розпізнає той самий OpenRouter. Zoom і миттєві сповіщення про пошту —
   необовʼязкові, додаються, коли захочете.

2. **Натисніть «Deploy with Vercel»** і вставте ці значення.
3. **Відкрийте свій сайт** `https://<ваш-проєкт>.vercel.app` — сторінка налаштування сама підключить Telegram-бота.
   Redirect URI налаштовувати не треба.
4. **Напишіть своєму боту `/start`** → «Підключити Google» → увійдіть у Google. Браузер покаже сторінку з помилкою
   на адресі `http://127.0.0.1…` — так і має бути: скопіюйте цю адресу й надішліть боту. Готово.

> 💡 Можна доручити все агенту **Claude Code** з підключеним Vercel MCP: «розгорни бота на Vercel». Він візьме
> інструкцію з `.claude/skills/deploy-vercel/SKILL.md`, спитає рівно ці 4 речі, перевірить їх і зробить решту сам.

### Необовʼязкові змінні

| Змінна | Навіщо |
|---|---|
| `BITRIX_WEBHOOK_URL` | задачі Bitrix24 — або простіше: у боті /settings → «🔗 Підключити Bitrix24» |
| `ZOOM_ACCOUNT_ID`, `ZOOM_CLIENT_ID`, `ZOOM_CLIENT_SECRET` | зустрічі в Zoom — або простіше: у боті /settings → «🔗 Підключити Zoom» |
| `GMAIL_PUBSUB_TOPIC` | власний топік Cloud Pub/Sub, якщо не хочете, щоб бот створив його сам |
| `AGENT_MODEL` | текстові запити: Supervisor і агенти календаря й пошти; типова — `openai/gpt-oss-120b` |
| `VISION_MODEL` | запити з картинками (скріншоти, фото); типова — `qwen/qwen3.7-flash` |
| `LLM_MODEL` | сильна модель: голосові запити й повторна спроба, якщо дешева не впоралась; типова — `openai/gpt-6-luna-pro` |
| `REMINDER_MINUTES` | за скільки хвилин нагадувати про зустріч (`30,10`) — див. «Нагадування» |
| `OWNER_NAME` | ваше імʼя для агентів (інакше — з Telegram) |
| `DEFAULT_DURATION_MIN` | тривалість зустрічі за замовчуванням (60) |
| `ENCRYPTION_KEY` | власний ключ шифрування доступу до Google (інакше виводиться з токена бота) |
| `CRON_SECRET` | закрити щоденний cron від сторонніх викликів |
| `PUBLIC_URL` | власний домен замість `*.vercel.app` |

| | |
|---|---|
| 📝 **Будь-який вхід** | текст, голосове, переслана переписка (серія збирається 8 с), скріншот |
| 🧠 **Агенти як у n8n** | очевидний запит («що в мене завтра?», «перевір пошту», відповідь на повідомлення бота) одразу йде потрібному агенту; незрозумілий — Supervisor вирішує, куди; агенти самі викликають інструменти Google. Кнопки ✅ / ❌ під запрошенням працюють без ШІ |
| 📅 **Календар** | розклад, вільний/зайнятий час, створення з Google Meet або Zoom (запрошення на пошту, нагадування за 10 хв), перенесення, учасники, нотатки, видалення, RSVP |
| 🔔 **Запрошення** | нова подія, куди вас запросили, — одразу в Telegram з кнопками ✅ Прийняти / ❌ Відхилити; перенесені й скасовані — теж; хто з гостей прийняв чи відхилив вашу зустріч — теж одразу |
| 💬 **Відповідь = контекст** | відповідайте на повідомлення про зустріч чи лист: «перенеси на завтра 15:00», «скасуй», «хто буде?», «відповідай, що згоден» |
| ✉️ **Gmail** | пошук і читання листів, надсилання, відповіді, чернетки, мітки, кошик (надсилання й видалення — після вашого «так»); про нові листи — «📧 Нова пошта!» одразу |
| 📋 **Задачі Bitrix24** | «мої задачі», «що горить», «що із задачею про звіт?» (стан — з коментарів), «постав Івану Петренку задачу … до пʼятниці» (людей шукає за імʼям у будь-якому відмінку), коментарі; /bitrix — списки, аналітика й Excel-звіт. Закривати, змінювати чи видаляти задачі бот не може |
| ⏰ **Нагадування** | щоранку — зустрічі на сьогодні; перед зустріччю — коли оберете (1 год … 5 хв); будить бота сам Google, без cron |
| 💸 **Дешеві моделі** | текст — `gpt-oss-120b`, картинки — `qwen3.7-flash`, голос — `gpt-6-luna-pro`; якщо дешева модель помилилась ще до будь-яких змін — запит повторюється на сильній. Порівняти моделі на своєму ключі: `OPENROUTER_API_KEY=… npm run eval:models` |
| 🧠 **Памʼять розмови** | останні 100 повідомлень (20 / 50 / 100 — у /settings → 🧠) і нотатка фактів («запамʼятай, що …») у прихованій папці застосунку на вашому Google Drive — не зникає при перезапусках; /reset — почати розмову заново |
| 📇 **Знайомі люди** | email людей, з якими ви вже зустрічались, агент бере з календаря — достатньо імені |
| 🛟 **Надійність** | 3 спроби на кожну фонову задачу, про помилки бот пише вам сам |

### Нагадування

- **Щоранку** (cron Vercel раз на добу, безкоштовно) бот надсилає список зустрічей на сьогодні.
- **Перед кожною зустріччю** — коли оберете: /settings → ⏰ (1 год, 30, 15, 10, 5 хв; типово 30 і 10). На кожен час — і повідомлення в
  Telegram, і сповіщення Google Calendar (/settings → ⏰ → «Куди»). Годинником служить сам Google: на зустріч бот ставить
  сповіщення календаря, а сигнал для Telegram — на її «тінь» у своєму календарі «AI-secretary · сигнали»; у потрібну хвилину Google надсилає
  лист, Gmail одразу будить бота, бот пересилає нагадування в Telegram і прибирає лист у кошик. Ні cron, ні сторонніх
  сервісів, ні опитування. Канал «Gmail → бот» (Cloud Pub/Sub у вашому ж проєкті Google Cloud) бот налаштовує сам —
  потрібно лише один раз увімкнути [Cloud Pub/Sub API](https://console.cloud.google.com/apis/library/pubsub.googleapis.com);
  якщо щось не так, /settings → ⏰ → «🔁 Перевірити» скаже, що саме.
- Події, створені ботом, мають і звичайне нагадування Google Calendar.

### Команди

Команди не потрібні — просто пишіть. Службові:

| Команда | Дія |
|---|---|
| `/start` | привітання й підключення Google |
| `/settings` | що підключено й що можна підключити; кнопками — коли нагадувати (1 год, 30, 15, 10, 5 хв) і ранковий список |
| `/bitrix` | задачі Bitrix24: мої, прострочені, аналітика, Excel-звіт |
| `/reset` | забути поточну розмову |
| `/help` | приклади запитів |

Інтерфейс бота — українською.

## 🏗 Як це працює

```
Telegram ─ webhook ─▶ /api/telegram ─────┐
Google   ─ push ────▶ /api/gcal-push ────┤                     ┌─▶ Google Calendar / Gmail API
Pub/Sub  ─ Gmail ───▶ /api/gmail-push ───┤  Vercel Functions   ├─▶ OpenRouter (LLM)
Браузер  ─ OAuth ───▶ /api/oauth/* ──────┼─────────────────────┼─▶ OpenRouter (голос → текст)
Cron (щодня) ───────▶ /api/cron/daily ───┤                     └─▶ Zoom
Ви ─────────────────▶ /api/setup ────────┘
```

- **Миттєва відповідь.** Функція одразу відповідає Telegram, а LLM, транскрибація й синхронізація виконуються
  після відповіді (`waitUntil`).
- **Push замість опитування.** `events.watch` → Google повідомляє про зміни → бот бере події, змінені за останні
  хвилини, і одразу пише вам про нові, перенесені чи скасовані (зроблені не ботом). Gmail — так само через Cloud
  Pub/Sub (бот налаштовує його сам). Той самий канал будить бота для нагадувань. Щоденний cron продовжує підписки.
- **Нуль ручної роботи.** Вебхук Telegram реєструє сторінка налаштування; створювати нічого не треба.
- **Безпека.** Перевірка власника на кожному вході, секрет вебхука Telegram, токен каналу Google, підписаний
  `state` в OAuth, доступ до Google зашифрований AES-256-GCM.

<details>
<summary><b>Без бази даних: де що живе</b></summary>

Функції Vercel нічого не памʼятають між запитами, тож бот тримає потрібне там, де воно й так є:

| Що | Де |
|---|---|
| Доступ до Google (зашифрований) | одне закріплене повідомлення «🔐 Google підключено» у вашому чаті з ботом |
| Памʼять розмови агентів | файл memory.json у прихованій папці застосунку на вашому Google Drive (appDataFolder): останні N повідомлень кожного агента + нотатка фактів; без дозволу Drive — лише в памʼяті запущеної функції |
| На яку зустріч / який лист ваша відповідь | прихований ідентифікатор у повідомленні, на яке ви відповідаєте |
| Вільні слоти, перетини, учасники | щоразу напряму з Google Calendar |
| Що вже повідомлено про подію | приватна (невидима гостям) позначка на самій події в Google Calendar |
| Які листи вже показано | прихована мітка в Gmail |
| Серія пересланих повідомлень | памʼять запущеної функції на кілька секунд — сама очищується |

Видалили закріплене повідомлення — бот попросить підключити Google знову. Більше нічого не губиться.
</details>

<summary><b>Структура проєкту</b></summary>

```
api/                 Vercel Functions (тонкі обгортки)
src/app.ts           HTTP-обробники, сторінка налаштування, фонові задачі
src/jobs.ts          фонові задачі з повторами
src/session.ts       коротка памʼять запущеної функції (серії повідомлень), сама очищується
src/agent/           Supervisor, агенти календаря й пошти, їхні інструменти, промпти (як у n8n)
src/bot/             /start і /settings, профіль власника, контакти з календаря
src/telegram/        Bot API, маршрутизація, перевірка власника, приховані дані в повідомленнях
src/google/          OAuth (доступ у закріпленому повідомленні), Calendar + Gmail API, push
src/zoom/            Zoom API
src/llm/, src/stt/   OpenRouter: ШІ і розпізнавання голосових
test/                тести (Telegram і Google замокані)
```
</details>

**Далі за планом:** записи зустрічей, транскрибація й підсумки.

## 🧑‍💻 Розробка

Потрібен лише **Node.js 22**.

```bash
npm ci
npm run typecheck
npm test          # усі зовнішні HTTP (Telegram, Google, OpenRouter) замокані
npm run dev       # локальний запуск через Vercel CLI
```

Змінні середовища — у `.env.example`.
